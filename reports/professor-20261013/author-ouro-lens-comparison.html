The author’s own-loop Ouro lenses closely match ours

Checked 16 October 2026. Downloaded all six base-Ouro banks from the author release, verified every file against its Hugging Face LFS SHA-256, and applied the four loop-end banks to Ouro residual states.

Same model checkpoint, same 476 loop-end source-to-target maps, and the same reference estimator. The matrices are not identical, but the own-loop readouts agree on the top token in 98.14% of 1,504 matched cells. All five previously selected professor-example concept ranks are unchanged. This supports consistency of the two implementations; it does not establish semantic accuracy.

The largest discrepancy is source 3 → target 191: cosine 0.7728, relative error 63.7%. This long cross-loop map is outside default own-loop routing. FP16 round-tripping our own-loop matrices alone changes them by about 0.021% on average, less than the observed 0.71–0.77% differences. The cause is not isolated by this audit; corpus, BOS behavior, numerical environment and fitting/merge batching are possible contributors.

Verification and use

For each of three live probes, both adapters produced exactly equal activations at all 192 sites on identical input IDs. Final logits matched the native checkpoint exactly, and stopping at an intermediate target preserved its state. On a tiny instance of the actual Ouro architecture, nine Jacobians spanning three target layers matched exactly. The imported author family passes the existing loader and exposes all 188 own-loop sources.

The new family is results/author-lens-20261016/family. Its target files link to the original author tensors; our existing fitted family and saved experiments are preserved. Runners accepting --family can use this directory. This comparison preceded switching the viewer default to the author family.

OMP_NUM_THREADS=4 .venv/bin/python compare_author_ouro_lens.py --device cuda:0
.venv/bin/python compare_author_ouro_lens.py --phase report

# Apply the author family using the existing runner:
.venv/bin/python fit_ouro_family.py --phase apply \
  --output-dir results/author-lens-20261016/family \
  --prompt "The capital of France is"

The comparison command uses the already downloaded pinned snapshot. The author’s fitting corpus is not supplied, so these results do not prove a fully identical fit or rank semantic quality. Causal interventions were not rerun. The mid-loop banks were inventoried and checksum-verified, but have no local counterpart and were not included in matched readouts.
